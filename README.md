# School Management System

A streamlined school management system built with Python to organize student records, administrative workflows, and academic tracking efficiently.

## Features
* Student record management
* Academic and administrative tracking
* Local database integration (`institution_system.db`)

## Getting Started

   ```bash
   git clone [https://github.com/muendomuthenyam/school-management-system.git](https://github.com/muendomuthenyam/school-management-system.git)
   python main.py
